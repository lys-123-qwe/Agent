# K线形态识别手册

## 单根K线形态

### 锤子线（Hammer）
- 特征：实体小（颜色不重要），下影线 ≥ 实体2倍，上影线极短或没有
- 出现位置：下跌趋势末端
- 含义：空方最后一次打压被多方强力反击，可能反转向上
- 确认信号：次日收阳线且收盘价高于锤子线实体
- 实战要点：配合支撑位使用，单独出现在下跌初期不可靠
- 量能配合：成交量放大增加可信度

### 倒锤子线（Inverted Hammer）
- 特征：上影线 ≥ 实体2倍，下影线极短，实体小
- 出现位置：下跌趋势末端
- 含义：多方试探性进攻，虽然被空方打回但已显反抗意图
- 确认信号：次日收阳线确认反转
- 注意事项：出现在上涨趋势顶部则为"流星线"，含义相反

### 十字星（Doji）
- 特征：开盘价 ≈ 收盘价，实体极小，上下影线长度不定
- 含义：多空力量均衡，市场犹豫不决
- 长腿十字星（上下影线都长）：趋势末端出现，反转信号强烈
- 墓碑十字星（上影线极长，无下影线）：顶部反转信号
- 蜻蜓十字星（下影线极长，无上影线）：底部反转信号

## 双根K线形态

### 吞没形态（Engulfing）
- 看涨吞没：下跌趋势中，一根阴线后跟阳线，阳线实体完全覆盖前一根阴线实体
- 看跌吞没：上涨趋势中，一根阳线后跟阴线，阴线实体完全覆盖前一根阳线实体
- 关键特征：第二根K线实体必须完全"吞没"第一根实体（影线不一定）
- 成交量：第二根K线成交量放大增强信号的可靠性
- 实战应用：吞没形态是最可靠的K线反转信号之一

### 刺透形态（Piercing Pattern）
- 特征：下跌趋势中，阴线后跟阳线，阳线收盘价插入前阴线实体50%以上
- 与吞没的区别：阳线实体没有完全覆盖前阴线，但收盘深入阴线内部
- 穿透越深（越接近阴线开盘价），反转信号越强
- 插入不足50%则不构成有效信号

### 乌云盖顶（Dark Cloud Cover）
- 特征：上涨趋势中，阳线后跟阴线，阴线收盘价插入前阳线实体50%以上
- 含义：多方狂欢中被空方强势反击，上涨动能衰竭
- 理想条件：阴线开盘高于阳线最高价（跳空高开），然后大幅回落

## 三根K线形态

### 启明星（Morning Star）
- 三根K线：长阴线 → 小实体（星，可阴可阳，可有缺口）→ 长阳线
- 含义：下跌→犹豫→多方反击，底部反转确认
- 理想条件：第三根阳线收盘超过第一根阴线实体的50%
- 变体：十字启明星（星为十字星）信号更强

### 黄昏星（Evening Star）
- 三根K线：长阳线 → 小实体（星）→ 长阴线
- 含义：上涨→犹豫→空方反击，顶部反转确认
- 出现位置：上涨趋势末端，尤其加速上涨后

### 三只乌鸦（Three Black Crows）
- 三根连续的长阴线，每根开盘都在前一根实体内，收盘创新低
- 含义：空方绝对主导，强势下跌信号
- 注意事项：三根阴线后市场常已超卖，追空风险大
- 位置关键：出现在上涨后更重要，盘整中出现意义减弱

## 形态优先级
1. 吞没形态 > 启明星/黄昏星 > 锤子线/倒锤子线
2. 出现在关键支撑/阻力位的形态更可靠
3. 成交量配合验证 → 信度+30%
4. 多时间框架共振 → 信度+40%
5. 结合 MA/RSI/MACD 确认，单一K线形态不构成交易依据
