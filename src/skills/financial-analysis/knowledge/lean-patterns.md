# QuantConnect/Lean 框架精华模式

## 5 层分离架构

| 层 | 职责 |
|---|---|
| Universe | 选股/选币范围 |
| Alpha | 生成 Insight 预测信号 |
| Risk | 风控过滤 |
| Execution | 下单执行 |
| Portfolio | 仓位分配 |

## Insight 体系

Lean 用 Insight 替代简单的 BUY/SELL：

- **Direction**: Up / Down / Flat
- **Period**: 预测有效期，如"12小时内"
- **Confidence**: 置信度 0~1
- **Magnitude**: 预测涨跌幅（可选）

对应当前金融分析输出：
- 方向：看涨/看空/震荡
- 有效期：1~3小时 / 3~6小时 / 6~12小时
- 置信度：20~95%
- 顶部/底部估算：基于布林上下轨与均线

## 状态机防抖（Hysteresis）

- RSI 超卖触发后，回到中性需要 RSI 升到 35 以上（而不是 30）
- 避免在边界处反复开平仓

## 风控与 Alpha 解耦

- Alpha 只管"看涨还是看跌"
- Risk 独立判断"能不能买"、仓位大小、是否熔断
- 最大回撤、杠杆上限、连续亏损熔断都应放在 Risk 层

## 对金融分析的启示

1. 输出应包含方向、置信度、有效期三个要素
2. 多指标综合评分比单一指标更稳健
3. 明确标注预测有效期，避免过期建议误导
4. 必须强调"仅供参考，不构成投资建议"
