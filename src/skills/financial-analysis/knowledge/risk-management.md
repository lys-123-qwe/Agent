# 风险管理与仓位控制

## 凯利公式（Kelly Criterion）

### 基础公式
> f* = (bp - q) / b
> f* = 最优仓位比例
> b = 盈亏比（平均盈利 / 平均亏损）
> p = 胜率
> q = 1 - p

### 实用简化
- 普通投资者建议使用 **半凯利**：f = f* / 2
- 若估计胜率 55%，盈亏比 2:1 → f* = 32.5% → 半凯利 = 16%
- 一次性投入不超过总资金20%，单一品种不超过10%

### 注意事项
- 凯利公式对胜率和盈亏比的估计误差敏感
- 高估胜率 → 过度下注 → 爆仓风险
- 宁可保守，不要激进

## 止损策略

### 固定比例止损
- 短线（1-5日）：止损 -3% ~ -5%
- 中线（1-4周）：止损 -8% ~ -12%
- 长线（1月以上）：止损 -15% ~ -20%
- 止损后不急于回补，至少观察1-2个交易日

### 技术止损
- 跌破 MA20 / MA60 → 减仓50%
- 跌破前低支撑 → 全仓止损
- 布林带下轨破位 → 趋势转弱确认

### 移动止损（Trailing Stop）
- 上涨中不断上移止损位
- 规则：止损 = 近期高点 × (1 - 回撤容忍度)
- 回撤容忍度：短线5%，中线10%，长线15%

### 时间止损
- 持仓超过预期时间仍未达目标 → 减仓或退出
- 避免"死扛"心态

## 最大回撤控制

### 组合层面
- 单日最大亏损不超过总资金 2%
- 连续回撤超过 15% → 暂停交易一周，复盘原因
- 月度亏损超过 10% → 缩仓至50%以下

### 单个品种
- 单品种亏损不超过总资金 1%
- 连续3次止损 → 暂停该品种交易，重新评估

## 仓位管理

### 金字塔加仓
- 首次建仓 30% → 盈利确认后加仓 40% → 趋势加速加仓 30%
- 加仓间距：突破关键阻力位后 / 回调至支撑位确认
- 决不亏损加仓（摊平成本是散户最大死因之一）

### 分散化原则
- 持有 3-5 个不相关品种（相关性 < 0.5）
- 行业分散：不在同一产业链上集中持仓
- 市场分散：A股 + 港股 + ETF 组合
- 股债比例：风险偏好高 → 股7债3；稳健 → 股5债5；保守 → 股3债7

### 动态再平衡
- 单一品种盈利超过20% → 减仓至初始比例
- 单一品种亏损触发止损 → 将资金分配给其他品种
- 每季度全面检查一次组合权重

## 风控红线（硬止损，不可妥协）
1. 不借钱炒股
2. 不重仓单一个股（>30%总资金）
3. 不追涨停板（打板）除非有完整止损计划
4. 不利好/利空消息改变原有止损纪律
5. 连续亏损3次后暂停交易3天
