# 宏观经济指标解读

## 通胀指标

### CPI（居民消费价格指数）
- 目标区间：中国 3% 左右
- CPI < 1%：通缩压力，消费不足 → 利好债券，利空消费股
- CPI 1%-3%：温和通胀，经济健康 → 利好股市
- CPI > 3%：通胀升温 → 央行可能收紧货币 → 利空高估值成长股
- 超预期 CPI：市场预期之外的通胀数据对市场冲击最大

### PPI（工业生产者出厂价格指数）
- PPI 上行 → 上游企业利润改善（资源/材料）
- PPI 下行 → 中下游成本降低（制造/消费）
- PPI-CPI 剪刀差：PPI > CPI → 上游利润好于下游；PPI < CPI → 下游利润好于上游
- PPI 转负 → 工业需求疲软 → 经济下行信号

## 货币与信用

### 社融（社会融资规模）
- 最全面的信用指标，领先 GDP 约 6 个月
- 社融增速回升 → 经济复苏预期 → 利好周期股
- 社融增速下滑 → 信用收紧 → 防御策略
- 结构比总量重要：企业中长期贷款占比高 → 实体经济信心足
- 居民中长期贷款（房贷）→ 领先房地产销售 1-3 个月

### M1 / M2
- M1（狭义货币）= 流通现金 + 活期存款
- M2（广义货币）= M1 + 定期存款 + 储蓄
- M1-M2 剪刀差：M1 增速 > M2 增速 → 资金活化，经济活跃
- M1 增速 < M2 增速 → 资金沉淀，经济低迷
- 历史经验：M1-M2 剪刀差转正领先股市上涨 3-6 个月

### LPR（贷款市场报价利率）
- 1年期 LPR：影响企业短期贷款和消费贷
- 5年期 LPR：影响房贷和企业中长期贷款
- LPR 下调 → 降成本 → 利好股市（尤其负债率高的行业如地产/基建）
- 非对称降息（5年期降得多）→ 稳地产意图明显
- 连续降息 → 确认宽松周期 → 利好成长股估值

### 降准（降低存款准备金率）
- 信号意义：释放流动性，支持实体经济
- 释放资金量：每降 0.5% 约释放 1 万亿长期资金
- 对股市：短期提振情绪，中期看资金是否真正流入实体
- 历史规律：降准后 1 个月 A 股上涨概率约 60%

## 增长指标

### PMI（采购经理人指数）
- 50 = 荣枯线
- PMI > 50：制造业扩张 → 经济向好
- PMI < 50：制造业收缩 → 经济承压
- 连续 3 个月下行 → 经济减速确认
- 财新 PMI vs 官方 PMI：官方覆盖大企业，财新覆盖中小出口企业
- PMI 分项中"新订单-产成品库存"领先产出一季度

### GDP
- 中国目标增速通常 5% 左右
- 高于预期 → 市场信心提振
- 低于预期 → 政策刺激预期升温（可能反而利好股市）
- 季度数据，滞后性强，更多看趋势

## 外部指标

### 人民币汇率（USD/CNY）
- 贬值（CNY 走弱）→ 外资流出压力 → 利空 A 股短期
- 升值（CNY 走强）→ 外资流入 → 利好蓝筹股
- 关注"7"整数关口，突破后情绪影响加大
- 贬值利好出口型企业（纺织/家电/电子代工）

### 美联储利率
- 加息 → 全球流动性收紧 → 新兴市场资金流出
- 降息 → 全球流动性宽松 → 利好新兴市场和大宗商品
- 中美利差（中国10年期 - 美国10年期）→ 倒挂时资金外流压力大

### 北向资金
- 连续净流入 → 外资看多中国 → 利好大消费/金融等外资重仓板块
- 连续净流出 → 避险信号
- 单日流入/流出超百亿 → 关注是否持续性行为
