# 行业轮动规律

## 美林投资时钟（Merrill Lynch Clock）

### 四个阶段与配置方向

| 阶段 | 经济特征 | 最优资产 | 强势板块 |
|------|---------|---------|---------|
| 复苏期 | 低通胀+经济上行 | 股票 | 可选消费、科技、工业 |
| 过热期 | 高通胀+经济上行 | 商品 | 能源、材料、工业 |
| 滞胀期 | 高通胀+经济下行 | 现金 | 公用事业、必需消费、医药 |
| 衰退期 | 低通胀+经济下行 | 债券 | 金融、公用事业 |

### 中国版时钟调整
- A股受政策影响大，时钟轮动速度快（通常3-6个月一轮）
- 流动性（社融/M2/降准降息）的权重高于经典时钟
- 产业政策可以打乱时钟节奏（如新能源补贴、半导体大基金）

## 板块轮动顺序（A股经验）

### 牛市级联路径
1. 券商/金融 → 2. 周期（有色/煤炭/钢铁）→ 3. 成长（科技/新能源）→ 4. 消费（白酒/医药）→ 5. 题材炒作
- 券商是牛市旗手，最先启动
- 成长股在中期弹性最大
- 消费防御性在末期受青睐

### 熊市防御路径
1. 高股息（银行/电力）→ 2. 必需消费 → 3. 公用事业
- 低估值+高分红是熊市避风港

### 近期热点轮动特征
- 政策驱动：消息一出即涨，持续性看落地力度
- 业绩驱动：财报季前后，超预期个股领涨
- 资金驱动：主力净流入持续为正的板块趋势更强

## 板块资金联动

### 资金面验证轮动
- 主力净流入前3的板块 → 关注轮动强度
- 连续3日主力净流入 → 构建趋势仓位
- 主力净流入转负 → 降低该板块权重
- 北向资金偏好板块 → 叠加外资审美溢价

### 产业链传导
- 上游涨价 → 中游成本承压 → 下游涨价预期（时滞1-3个月）
- 期货价格 → 股票价格：通常期货领先股票1-3个交易日
- 例如：碳酸锂涨 → 锂矿股涨 → 电池成本上升 → 整车利润挤压

## 轮动策略框架
1. 识别当前时钟位置（看CPI/PMI/社融）
2. 确定强势板块（量价+资金流向交叉验证）
3. 布局2-3个相关板块（不过度集中）
4. 设置轮动退出条件（涨跌幅偏离均值2σ / 主力资金转负）
5. 定期再平衡（2-4周检查一次）
