# 量价关系分析

## 核心原则
量在价先——成交量的变化往往领先于价格的变化。价格可以骗人，成交量很难骗人。

## 量价八法（经典）

### 1. 量增价涨（健康上涨）
- 特征：成交量放大配合价格上涨
- 含义：上涨得到资金认可，趋势健康
- 实战：持股待涨，回调可加仓
- 风险：连续放量后突然缩量 → 动能衰竭信号

### 2. 量缩价涨（背离上涨）
- 特征：价格创新高但成交量递减
- 含义：上涨动能减弱，买方意愿下降
- 风险：顶部背离信号，可能即将回调
- 例外：控盘度高的庄股可以无量上涨，需结合流通盘判断

### 3. 量增价跌（恐慌下跌）
- 特征：成交量放大配合价格下跌
- 含义：恐慌性抛售，空方力量释放中
- 注意：放量急跌可能是赶底，缩量缓跌才是阴跌
- 判断：急跌放量后缩量企稳 → 大概率见底

### 4. 量缩价跌（阴跌）
- 特征：价格下跌伴随成交量萎缩
- 含义：买方离场，卖压不重但无人接盘
- 风险：阴跌往往持续时间长，难以判断底部
- 策略：不要抄底，等待放量反转信号

### 5. 天量天价（阶段见顶）
- 特征：成交量创近期新高，价格也创近期新高
- 含义：多空分歧达到极致，可能是主力出货
- 判断标准：成交量超过前一日2倍以上，或突破20日均量3倍
- 实战：天量出现后3日内大概率见阶段顶部

### 6. 地量地价（阶段见底）
- 特征：成交量萎缩至极低水平
- 含义：交易极度冷清，无人愿卖也无人愿买
- 判断标准：成交量低于20日均量的一半以下
- 注意：地量后不一定立刻涨，可能继续磨底

## 特殊信号

### 放量突破
- 价格突破关键阻力位（前高/均线/布林上轨）同时成交量放大
- 突破有效性：放量突破 + 3日不回撤 = 有效突破
- 缩量突破为假突破概率高

### 缩量回调
- 上涨趋势中价格回调但成交量萎缩
- 含义：卖方力量枯竭，回调接近结束
- 买点：缩量至启动前水平 + 价格企稳

### 底部放量
- 长期下跌后突然放量上涨
- 含义：主力资金入场信号
- 确认：次日继续放量上涨 → 反转概率高；次日缩量下跌 → 一日游行情

## 量价与板块联动
- 龙头股放量领涨 → 板块共振，趋势可信
- 板块涨但龙头缩量 → 资金接力不足，警惕分化
- 资金流向（主力净流入）+ 放量 = 最强配合信号
