## financial_analysis 工具

### 触发方式
用户提到"分析/诊断/建议/走势/行情分析/投资分析/推荐"等关键词时触发。

### 调用示例
```json
{"query": "分析沪深300ETF"}
{"query": "现在适合买什么基金"}
```

### 工作流程
1. 根据 query 判断标的类型（股票/基金/期货）
2. 并行获取标的实时行情和历史走势
3. 调用 DeepSeek 生成分析报告
4. 报告含：基本面分析、技术面分析、风险提示、投资建议

### 注意事项
- 所有金融分析回复末尾必须附带风险提示（投资有风险，入市需谨慎）
- 分析报告仅供参考，不构成投资建议
