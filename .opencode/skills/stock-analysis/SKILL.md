## get_stock 工具

### 实时行情
```json
{"stock": "贵州茅台"}
```

### 走势图（折线图，默认）
```json
{"stock": "贵州茅台", "days": 30}
```

### K线图（蜡烛图）
```json
{"stock": "贵州茅台", "days": 30, "chart_type": "candlestick"}
```

### 参数说明
- `stock`（必填）：名称或代码，如 贵州茅台 / 600519 / sh600519 / AAPL
- `days`（可选）：7=近一周，30=近一月，90=近三月。不填=仅实时行情
- `chart_type`（可选）：`line`=折线图（默认），`candlestick`=K线图。仅 A 股支持图表

### 返回值说明
- 实时行情：含当前价、涨跌幅、今开、昨收、最高、最低、成交量、市盈率、市净率、总市值
- 走势图：图片已通过 CDN 上传并发送到微信，文字摘要含区间涨跌幅
