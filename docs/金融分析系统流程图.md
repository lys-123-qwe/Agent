## 四、AIService Function Calling 主循环

```
用户消息 → AIService.chat(userId, userMessage, tools)
      │
      ▼
┌─────────────────────────────────────────────────────────────────┐
│  1. 从 sessions 获取/创建对话历史                                 │
│  2. 追加用户消息到 history                                        │
│  3. 注入系统 Prompt（含日期、用户画像）                           │
│  4. 注入 RAG 知识库上下文（如有）                                 │
└─────────────────────────────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────────────────────────────┐
│  发送请求到 DeepSeek:                                            │
│  POST {aiApiUrl}/v1/chat/completions                             │
│  {                                                               │
│    model: "deepseek-v4-pro",                                     │
│    messages: [...history],                                       │
│    tools: [...toolDefinitions]                                   │
│  }                                                               │
└─────────────────────────────────────────────────────────────────┘
      │
      ▼
  ┌──────────────────────────────┐
  │ DeepSeek 返回 choice          │
  │ finish_reason = ?             │
  └──────┬───────────────────────┘
         │
    ┌────┴────────────┐
    │                 │
  "stop"          "tool_calls"
    │                 │
    ▼                 ▼
┌────────┐    ┌──────────────────────────────────────────────┐
│ 纯文本  │    │  工具调用循环 (最多5轮)                       │
│ 回复   │    │                                              │
│        │    │  for each tool_call in response:              │
│        │    │    1. ToolRegistry.findTool(name)             │
│        │    │    2. tool.execute(arguments)                 │
│        │    │    3. 收集 ToolResult (text/image/audio)      │
│        │    │    4. 同一工具连续失败2次 → 跳过              │
│        │    │                                              │
│        │    │  将 tool results 回传给 DeepSeek              │
│        │    │  DeepSeek 生成最终回复                        │
│        │    │                                              │
│        │    │  返回 ChatResult {                            │
│        │    │    replyText: "...",                          │
│        │    │    pendingMedia: [ToolResult...]              │
│        │    │  }                                           │
│        │    │                                              │
│        │    │  ┌─────────────────────────────────┐        │
```

```
  - 数据解读指引 (涨跌幅阈值、成交量信号、资金面验证...)
  - 输出格式: 四段式 (速览→深度→研判→风险)
  - 强制 emoji + 免责声明

类型专属框架 (switch 追加):

  STOCK_ANALYSIS:
    + 当日走势 + 短期趋势 + 估值参考 + 关注点

  SECTOR_ANALYSIS:
    + 产业链全景 + 价格传导 + 资金面验证(主力vs散户)
    + 盈利弹性 + 产能周期 + 配置建议

  CROSS_MARKET:
    + 核心驱动因子 + 期货→股票传导
    + 股票→基金传导 + 汇率/利率冲击 + 套利/对冲思路

  FUND_ANALYSIS:
    + 净值表现 + 风险收益 + 持仓透视
    + 费效比 + 横向对比 + 适合人群

  PORTFOLIO_DIAGNOSIS:
    + 相关性分析 + 集中度风险 + 风格暴露
    + 压力测试 + 优化建议

  FUTURES_TREND:
    + 价格趋势 + 基差结构 + 供需分析
    + 资金面 + 关键价位

  MARKET_OVERVIEW:
    + 指数全景 + 市场情绪 + 风格轮动
    + 资金信号(北向资金/主力偏好) + 外部环境 + 短期研判
```
